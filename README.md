## 🎯 About the Project

TechVers is the official marketing and lead-generation website for **TechVers Digital Innovation**, a full-service tech agency with 7+ years of engineering experience. The site showcases services, live projects, team, and a contact CTA — with a fully integrated inquiry form that saves leads to MongoDB.

**Key highlights:**
- 300+ sites built, 10M+ users served on live platforms
- Services spanning Web Dev, Mobile Apps, AI Solutions, WhatsApp Automation, and more
- Production-ready contact form with DB persistence and validation

## 🛠 Tech Stack

### Frontend
| Layer | Technology |
|---|---|
| Framework | React 18 with Vite |
| Bundler | Vite (with HMR via Oxc / SWC) |
| Styling | CSS Modules / Tailwind CSS |
| Linting | ESLint |

### Backend
| Layer | Technology |
|---|---|
| Runtime | Node.js |
| Framework | Express.js |
| Database | MongoDB (via Mongoose) |
| Config | dotenv |
